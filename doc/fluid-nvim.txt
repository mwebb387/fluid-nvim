INTRO                                                      *fluid-nvim-intro*

Fluid-nvim is a framework for expressive and "fluid" Neovim configuration
using fluent syntax. It provides a modular approach to Neovim configuration
with a chainable API that makes configuration files more readable and 
maintainable.

Key features:
  • Fluent, chainable API for configuration
  • Modular plugin architecture with opt-in modules  
  • Automatic plugin management and installation
  • Dependency resolution between modules
  • Clean separation of concerns


==============================================================================
INSTALLATION                                        *fluid-nvim-installation*

1. Clone fluid-nvim to your Neovim configuration directory: >

    git clone https://github.com/yourusername/fluid-nvim \
      ~/.config/nvim/pack/config/opt/fluid

2. Add fluid-nvim to your init.lua: >

    vim.opt.rtp:prepend('~/.config/nvim/pack/config/opt/fluid')
    
    local fluid = require('fluid')
    fluid:setup(function(f)
      -- Your configuration here
    end)

USAGE                                                        *fluid-nvim-usage*

Basic usage involves calling modules and options using fluid's chainable API: >

    local fluid = require('fluid')
    fluid:setup(function(f)
      f:telescope()
        :lsp()
        :treesitter()
    end)

Modules can be configured with options: >

    f:lsp():options('icons', 'server_management')
      :telescope()

The fluent syntax supports multiple operators:
  • Function call: `f:module()`
  • Addition: `f + module`  
  • Modulo: `f % module`
  • Division: `f / module`
  • Multiplication for options: `f * option`
  • Subtraction for options: `f - option`


==============================================================================
CONFIGURATION                                        *fluid-nvim-configuration*

Fluid-nvim uses a two-phase setup:

1. **Init Phase**: Modules declare dependencies and plugins
2. **Setup Phase**: Modules configure their functionality

Each module can define:
  • `init()` - Called during the init phase to set up dependencies
  • `setup(deps)` - Called after plugins are installed with resolved deps
  • `options` - Available configuration options  
  • `dependencies` - Required modules or packages

Default configuration is applied from `config-default.lua` which sets up
basic Neovim options like split behavior, line numbers, and completion.

API                                                          *fluid-nvim-api*

The fluid API provides methods for configuring Neovim and managing modules.

                                                              *fluid:setup()*
fluid:setup({config})
    Initialize fluid-nvim with the given configuration function or table.
    
    Parameters: ~
        {config} (function|table) Configuration function that receives the
                 fluid instance, or a table with an `init` function.

                                                             *fluid:module()*
fluid:module({name})
    Load and configure a module by name.
    
    Parameters: ~
        {name} (string) The module name to load.
        
    Returns: ~
        fluid instance for chaining

                                                             *fluid:option()*
fluid:option({name})
    Add an option to the current module.
    
    Parameters: ~
        {name} (string) The option name to enable.
        
    Returns: ~
        fluid instance for chaining

                                                            *fluid:options()*
fluid:options({...})
    Add multiple options to the current module.
    
    Parameters: ~
        {...} (string) Variable number of option names.
        
    Returns: ~
        fluid instance for chaining
